# Climate Data Harmonization Agent Wiki

Welcome to the documentation hub for the Climate Data Harmonization Agent, a user-centred pipeline for acquiring, harmonizing, validating, diagnosing, and delivering climate datasets for impact modelling and decision-support applications.

## Intended audiences

This Wiki is intended for:

- ILRI Climate Services and impact-modelling teams;
- Climate Data Hub managers and developers;
- national meteorological and hydrological services;
- agriculture, livestock, food-security, and disaster-risk institutions;
- researchers and data engineers; and
- users preparing model-ready climate datasets.

## Documentation principles

Wiki pages should distinguish implemented functionality from planned work, identify the software version or commit being described, document source-data licences and limitations, and link to reproducible run evidence where possible.

## Support channels

Use GitHub Issues for reproducible bugs and scoped feature requests. Use GitHub Discussions for questions, ideas, demonstrations, scientific-method discussions, and stakeholder feedback.
